# Скрипты резервного копирования и восстановления

Комплекс автоматизации отказоустойчивости SkillShare Network (Спринт 4).
Все доступы к БД берутся из корневого `.env` (`SSN_DATABASE_URL`) — паролей в коде нет.

| Файл | Назначение |
|------|------------|
| `_env.sh` | Общий модуль: разбор `.env` / DSN, выбор режима запуска утилит PostgreSQL |
| `backup.sh` | Горячий дамп БД (`pg_dump`) + архив медиа `backend/app/static` в `.tar.gz` |
| `restore.sh` | Восстановление БД из дампа + распаковка медиа обратно в приложение |

Готовые дампы и архивы складываются в `backups/data/` — этот каталог в `.gitignore`,
на GitHub уходят только тексты `.sh`-скриптов.

## Режимы запуска

| Сценарий | Команда |
|----------|---------|
| Локально (нативный PostgreSQL на PATH) | `./scripts/backup.sh` |
| Локально, бинарники не на PATH | `PG_BIN=/путь/к/bin ./scripts/backup.sh` |
| Внутри Docker-окружения | `DB_CONTAINER=db ./scripts/backup.sh` |

## Резервное копирование

```bash
./scripts/backup.sh
# => backups/data/db_backup_2026_06_11_143000.sql
# => backups/data/media_backup_2026_06_11_143000.tar.gz
```

Имена файлов содержат дату и время, поэтому бэкапы не перезатирают друг друга.

## Восстановление «из нуля»

```bash
./scripts/restore.sh                       # самый свежий бэкап
./scripts/restore.sh backups/data/db_backup_2026_06_11_143000.sql
FORCE=1 ./scripts/restore.sh               # без подтверждения (для CI/демо)
```

`restore.sh` подбирает парный медиа-архив по таймстампу из имени дампа. Дамп
создаётся с `--clean --if-exists`, поэтому существующие объекты дропаются перед
накатом — база восстанавливается в чистое состояние.

## Сценарий «симуляция катастрофы» (демонстрация)

```bash
./scripts/backup.sh                        # 1. снять бэкап
psql ... -c 'DROP SCHEMA public CASCADE; CREATE SCHEMA public;'  # 2. «авария»
rm -rf backend/app/static/*                # 3. стереть медиа
./scripts/restore.sh                       # 4. восстановить одной командой
```

После восстановления перезапустите приложение — данные и медиа вернутся на места.
